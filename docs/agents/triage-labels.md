# Triage 标签

工程技能中的五个规范角色与本仓库 GitHub 标签一一对应：

| 规范角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者尚需评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格充分，可由异步 Agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或决策 |
| `wontfix` | `wontfix` | 不处理 |

后续若修改 GitHub 标签词汇，应同步更新本表右列。
